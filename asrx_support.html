Quick Start

Open ASRxSTUDIO and drag an audio or video file into the queue.
Click Transcribe. File transcription uses the bundled VibeVoice runtime on your Mac.
Review speaker labels and timestamps, then export SRT, VTT, TXT, Markdown, JSON, or DOCX.

Requirements

ASRxSTUDIO is built for Apple Silicon Macs.

macOS 14 or later Apple Silicon Microphone permission for Live Captions Speech Recognition permission for Live Captions

Long media files and bundled speech models can require significant disk space and memory. Keep enough free disk space before importing large video files.

Privacy

Normal file transcription is processed locally. ASRX does not upload your audio, video, transcript, subtitle, glossary, or project data to ASRX servers during the standard file workflow.

Live Captions use Apple macOS Speech Recognition after you grant permission.

Troubleshooting

Live Captions do not hear speech

  • Open System Settings → Privacy & Security → Microphone, then confirm ASRxSTUDIO is allowed.
  • Open System Settings → Privacy & Security → Speech Recognition, then confirm ASRxSTUDIO is allowed.
  • Open System Settings → Sound → Input and choose an active microphone, such as MacBook Microphone or your external input device.
  • Quit and reopen ASRxSTUDIO after changing microphone or speech permissions.

File transcription does not start

  • Make sure the media file is stored locally and is not still downloading from iCloud Drive or another sync provider.
  • Try a shorter audio file to confirm the bundled runtime is working.
  • Check that your Mac has enough free disk space for temporary audio extraction and exported subtitle files.

SRT or VTT export looks wrong

  • Open the transcript editor and check whether timestamps are monotonic and speaker edits were saved.
  • Use subtitle preview to inspect line wrapping before exporting again.
  • If a long file has drift, export a small section first and include the original duration when contacting support.
