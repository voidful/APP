inpiano Support

Need help with inpiano? We are happy to help.

Contact

Email support: support@eric-lam.com

Please include your device model, iOS version, and a short description of the issue.

Purchases

inpiano uses Apple In-App Purchase for the full unlock. If you already purchased the unlock, use Restore Purchases inside the app.

Imported Scores

Imported score files stay on your device. If a file cannot be opened, check that it is in a supported inpiano, PM, or JSON score format.
