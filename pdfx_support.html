Open And Save PDFs

  • Use Open PDF to choose a local PDF file.
  • Use Save to write edits back to the current file.
  • Use Save As to export a separate PDF copy.

Text, Signature, Images

  • Use Text to place editable text boxes on the page.
  • Use Sign to draw a signature or import one from iPhone/iPad when available.
  • Use Insert Image or Paste Image to place images.

Shapes And Selection

  • Use Shape to add rectangles, ellipses, lines, arrows, and other marks.
  • Select an object to move, resize, rotate, recolor, or delete it.
  • The Inspector opens when an object is selected and can be collapsed when not needed.

Reduce PDF Size

Reduce PDF Size creates a smaller flattened PDF copy. This can reduce editability and text selection in exchange for a lighter file.

Privacy

PDFX works with user-selected local files and does not require an account, analytics, ads, tracking, or cloud sync.
